# 적정 재고일수 자동 산출·검증 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 요청자 엑셀 구조의 xlsx를 읽어 SKU별 가중평균·실적기준·FCST기준 적정 재고일수를 계산하고, 엑셀 값과 대조하며, 8/24 이후 실제 출고(W35~W43)로 사후 검증한 결과 xlsx를 만든다.

**Architecture:** 세 영역 패키지(`purchase_master`, `mp_simulation`, `inventory_days`)와 공통 xlsx 유틸(`common`)로 나눈다. 읽기는 각 영역의 `loader.py`, 계산·대조·검증은 입출력 없는 순수 함수, 쓰기는 `inventory_days/report.py`만 한다. `__main__.py`가 이들을 엮는다.

**Tech Stack:** Python ≥3.12(설치본 3.15), uv, openpyxl, pytest, 표준 `statistics`.

**Spec:** `docs/superpowers/specs/2026-11-19-적정재고일수-자동산출-design.md`

## Review Focus

1. 시트마다 SKU 표기에 앞뒤 공백이 있거나 대소문자가 다름 → 같은 SKU로 합쳐야 한다(Task 1 `norm_sku` 테스트).
2. 제목 행이 1행이 아닌 버전(구매마스터 6행, Summary 11~12행) → 제목 행을 찾아 읽어야 한다(Task 2·4 테스트).
3. 숫자가 텍스트로 저장됨(`'1,036'`, `'10.26%'`, `'#N/A'`, `'#DIV/0!'`, `'(13)'`) → 숫자 또는 None으로 바뀌어야 한다(Task 1 테스트).
4. 같은 SKU가 여러 행: FCST는 첫 행(XLOOKUP과 같게), 현재고는 창고별 합산(Task 3·4 테스트).
5. 리드타임이 검증 구간(63일)보다 길거나 수요가 0 → 결품 방어율·일수에서 빠지고 오류 없이 None(Task 5·7 테스트).

### Task 1: 프로젝트 골격과 공통 xlsx 유틸

**Interfaces:**
- Produces:
  - `class InputError(Exception)` — 사용자에게 보여줄 입력 오류(시트·열 이름 포함 메시지)
  - `norm_sku(v) -> str | None` — 문자열화, 앞뒤 공백 제거, 대문자. 빈 값 None
  - `norm_header(v) -> str` — 공백·줄바꿈 모두 제거(`'기존\n안전재고일수'` → `'기존안전재고일수'`)
  - `to_number(v) -> float | None` — int/float는 float, 문자열은 쉼표 제거·`%`는 /100·`(x)`는 -x·빈 문자열과 `#`으로 시작하는 오류값은 None, 그 밖의 텍스트는 None. datetime 등은 None
  - `find_sheet(wb, *keywords: str) -> Worksheet` — 정확히 같은 이름 우선, 없으면 이름에 키워드가 포함된 첫 시트. 없으면 `InputError`(찾은 키워드와 시트 목록 포함)
  - `find_header_row(ws, required: str, max_scan: int = 30) -> int` — 위에서부터 `norm_header(셀) == norm_header(required)`인 셀이 있는 첫 행 번호. 없으면 `InputError`
  - `header_map(ws, row: int) -> dict[str, int]` — `norm_header(제목)` → 열 번호(1부터), 같은 제목은 처음 나온 열
  - `require_cols(hmap, names: list[str], sheet: str) -> list[int]` — 없는 열이 있으면 `InputError("시트 '…'에 열이 없습니다: …")`
- `tests/conftest.py`: `make_wb(sheets: dict[str, list[list]]) -> Workbook` — 시트 이름 → 행 목록(1행부터)으로 메모리 통합문서를 만든다.
