# 발표자료 공개본 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 대학원생에게 배포할 15장짜리 공개본 발표자료를 만든다. 사내 정보는 비식별 처리하고, 숫자는 실제 결과를 그대로 쓰며, 금지어 자동 검사를 통과해야 한다.

**Architecture:** 별도 원본 `presentation/build_public.js`가 `presentation/data.json`을 읽어 pptx를 만든다. 사내본 `build.js`는 건드리지 않는다. `presentation/leak_check.py`는 결과 pptx의 모든 글자를 훑는다. 금지어 목록은 data.json에서 뽑은 것과 고정 목록을 합친 것이다. 금지어가 나오거나 장 수가 넘치면 실패로 끝난다.

**Tech Stack:** Node 26 + pptxgenjs 4 + jszip(기존 `presentation/node_modules`), Python 3.12 표준 라이브러리(zipfile, re), pytest(uv)

**Spec:** `docs/superpowers/specs/2026-11-20-발표자료-공개본-design.md`

## Global Constraints

- 모든 글자, 주석, 커밋 메시지는 한국어로 쓴다. 코드 식별자는 영어로 쓴다.
- 문서에 "서론", "본론", "결론"이라는 말을 쓰지 않는다.
- 15장 이하로 만든다.
- 품목그룹은 "그룹 A~G"로 표시한다. 순서는 `D.metrics[g]['가중평균'].n_demand` 내림차순이고, 같으면 코드 오름차순이다. 실제 그룹 코드 문자열을 코드에 하드코딩하지 않는다.
- SKU 코드와 제품명은 쓰지 않는다. 사례 품목은 "품목 X"로 쓴다.
- 절대 수량은 쓰지 않는다. 출고량, 수요량, 발주점, 현재고, 목표재고량, 주수요 합계가 해당한다. 비율(%), 일수, 배수, SKU 수, 주차 번호만 쓴다.
- 산식은 두 개만 쓴다: `가중평균 수요 = w·실적 + (1−w)·예측`, `안전재고 = Z·σ·√LT`. Z 숫자값, 재고등급 점수·백분위 규칙, 보정계수는 쓰지 않는다.
- 다음 단어는 쓰지 않는다: MP, ITSM, SCM, WMS, 구매마스터, Logic, 사진, 가상, 엑셀, xlsx, 실제 날짜(8/24, 8/28, 0824, 20260828).
- 데이터는 "테스트 데이터셋(비식별 처리)"으로 표기한다. 꼬리말 왼쪽에는 `AI 기반 적정 재고일수 산출 · 테스트 데이터 기반`을 넣고, 오른쪽에는 쪽 번호를 넣는다. 근거 파일 경로와 작성자는 넣지 않는다.
- 숫자는 모두 data.json에서 읽는다. 손으로 적은 수치는 없다.
- 양식은 사내본과 같다: 16:9(LAYOUT_WIDE), 맑은 고딕, 남색 `1B2E44` / 청록 `0B7F80` 팔레트, 제목은 결론 한 문장, 부제 한 줄, 오른쪽 위 태그. 저장할 때 `lang="ko-KR"` 후처리도 사내본과 같이 한다.

## Review Focus

1. 문서 속성(`docProps/core.xml`의 title·subject)에 사내 과제명이 남는 경우 → leak_check가 슬라이드뿐 아니라 docProps도 훑어야 한다(Task 1 테스트 `test_collect_text_includes_doc_props`).
2. 글자 run이 쪼개져 금지어가 run 경계에 걸리는 경우(예: "X" + "YZ") → 한 문단 안의 run은 붙여서 검사한다(Task 1 `test_runs_joined_within_paragraph`).
3. 짧은 영문 코드가 일반 단어에 들어 있는 경우(예: "ABC"가 "ABCDEF"에 포함) → 영문 금지어는 영숫자 경계로만 찾는다(Task 1 `test_ascii_term_word_boundary`).
4. 제품명 일부만 노출되는 경우(예: 제품명 속 단어 하나) → 제품명을 공백·괄호·쉼표로 나눈 2글자 이상 조각도 금지어에 넣는다(Task 1 `test_forbidden_terms_from_data`).
5. data.json에서 weight_search가 비어 있는 경우 → build_public.js는 사내본처럼 "산출 예정"으로 채우지 않는다. 대신 명확한 오류로 멈춘다. 공개본에서는 결과가 핵심이기 때문이다(Task 2 Step 3).

### Task 1: 금지어 검사 `leak_check.py`

**Files:**
- Create: `presentation/leak_check.py`
- Test: `tests/presentation/__init__.py`(빈 파일), `tests/presentation/test_leak_check.py`

**Interfaces:**
- Produces:
  - `collect_text(pptx_path: Path) -> dict[str, str]`
    - 키는 zip 안 경로이고, 값은 그 부분의 글자다.
    - 대상: `ppt/slides/slide*.xml`, `ppt/notesSlides/*.xml`, `docProps/core.xml`, `docProps/app.xml`
    - 슬라이드와 노트: `<a:p>` 안의 `<a:t>`는 이어 붙이고, 문단끼리는 `\n`으로 나눈다.
    - docProps: 태그를 지운 글자를 쓴다. XML 엔티티는 풀어 쓴다.
  - `forbidden_terms(data: dict) -> list[str]`
    - 다음을 중복 없이 모은다.
      - data.json에서 뽑는 것:
        - `metrics` 키 중 '전체'·'공통'·'미분류'를 뺀 그룹 코드, `weights[].group`
        - `case`·`counter_case`의 `sku`와 `name`, `top.rows[].sku`
        - `name`을 `[\s()\[\],/·]+`로 나눈 2글자 이상 조각
      - 고정 목록 `FIXED_TERMS`: MP, ITSM, SCM, WMS, 구매마스터, Logic, 사진, 가상, 엑셀, xlsx, 8/24, 8/28, 0824, 20260828, 1.645, 1.282, 1.036, 보정계수, 서론, 본론, 결론
  - `find_leaks(texts: dict[str, str], terms: list[str]) -> list[tuple[str, str]]`
    - 반환값은 (zip 경로, 금지어) 목록이다.
    - 영문·숫자로만 된 금지어는 `(?<![A-Za-z0-9])term(?![A-Za-z0-9])`로 찾는다.
    - 그 밖의 금지어는 부분 문자열로 찾는다.
  - `count_slides(pptx_path: Path) -> int`
  - CLI: `uv run python presentation/leak_check.py <pptx> [--data presentation/data.json] [--max-slides 15]`
    - 누출이 있으면 하나씩 `slide3.xml: 'XYZ'` 형식으로 출력한다.
    - 장 수가 넘치면 그 사실을 출력한다. 둘 중 하나라도 있으면 종료 코드 1이다.
    - 문제가 없으면 `금지어 0건 · N장`을 출력하고 종료 코드 0이다.

- [ ] **Step 1: 실패하는 테스트 작성**

테스트에서 pptx는 실제 파일 대신 `zipfile`로 직접 만든다. 도우미 `make_pptx(tmp_path, slides: list[str], core: str = '') -> Path`를 쓴다. 테스트 파일은 `sys.path`에 `presentation/`을 넣어 `import leak_check`한다.

```python
def test_runs_joined_within_paragraph(tmp_path):
    p = make_pptx(tmp_path, ['<a:p><a:r><a:t>X</a:t></a:r><a:r><a:t>YZ 그룹</a:t></a:r></a:p>'])
    assert collect_text(p)['ppt/slides/slide1.xml'] == 'XYZ 그룹'

def test_paragraphs_separated(tmp_path):
    p = make_pptx(tmp_path, ['<a:p><a:r><a:t>M</a:t></a:r></a:p><a:p><a:r><a:t>P</a:t></a:r></a:p>'])
    assert find_leaks(collect_text(p), ['MP']) == []

def test_collect_text_includes_doc_props(tmp_path):
    p = make_pptx(tmp_path, ['<a:p><a:r><a:t>안녕</a:t></a:r></a:p>'], core='<dc:title>MP 시스템 &amp; 과제</dc:title>')
    assert 'MP 시스템 & 과제' in collect_text(p)['docProps/core.xml']

def test_ascii_term_word_boundary():
    texts = {'s': 'ABCDEF · TEMPO · 그룹 A'}
    assert find_leaks(texts, ['ABC', 'MP']) == []
    assert find_leaks({'s': 'ABC 그룹'}, ['ABC']) == [('s', 'ABC')]

def test_korean_term_substring():
    assert find_leaks({'s': '테스트용 가상데이터'}, ['가상']) == [('s', '가상')]

def test_forbidden_terms_from_data():
    data = {'metrics': {'전체': {}, '공통': {}, 'ABC': {}}, 'weights': [{'group': 'ABC'}, {'group': 'XYZ'}],
            'case': {'sku': 'ABC123', 'name': '가나다품 라마바(QA,QB)'},
            'counter_case': {'sku': 'XYZ9', 'name': '샘플 품목 Q'},
            'top': {'rows': [{'sku': 'QQQ1'}]}}
    t = forbidden_terms(data)
    for w in ['ABC', 'XYZ', 'ABC123', 'XYZ9', 'QQQ1', '가나다품 라마바(QA,QB)', '가나다품', '라마바', 'QA', 'QB', '샘플', '품목', 'MP', '서론']:
        assert w in t
    assert 'Q' not in t and '전체' not in t

def test_count_slides(tmp_path):
    p = make_pptx(tmp_path, ['<a:p/>', '<a:p/>', '<a:p/>'])
    assert count_slides(p) == 3

def test_cli_exit_codes(tmp_path):
    # data.json 대용 파일과 pptx 두 개(깨끗한 것, 누출 있는 것)로 main(argv)의 반환값 0 / 1 확인
    ...
```
