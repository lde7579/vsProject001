# 재고등급 자동 산출 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 구매마스터의 원재료 값으로 재고등급을 계산해 Z값에 쓰고, 엑셀 등급과 대조해 결과 xlsx에 보이며, 산식과 어긋난 칸만 고친 가상 보완본을 만드는 도구를 둔다.

**Architecture:**
- 등급 계산은 `purchase_master/grade.py`의 순수 함수로 둔다.
- 로더가 등급 입력 열을 더 읽는다. `run()`이 등급을 계산해 `build_inputs`에 넘긴다. `report`는 `재고등급` 시트를 쓴다.
- 가상 보완본 도구(`safety_stock.virtual_data`)는 기존 로더·계산·대조 결과를 그대로 다시 써서 엑셀 칸을 고친다.

**Tech Stack:** Python 3.12, openpyxl, pytest, uv

**Spec:** `docs/superpowers/specs/2026-11-20-재고등급-자동산출-design.md`

## Global Constraints

- 코드 주석·docstring·커밋 메시지·README는 한국어로 쓴다. 식별자는 영어로 둔다.
- 등급 경계: 백분위 ≥ 0.75 → A, ≥ 0.26 → B, 그 외 C. 백분위 = `x보다 작은 값의 개수/(n−1)`를 소수 셋째 자리에서 **내림**한다(부동소수 오차 보정 `+1e-9` 후 floor). n = 1이면 1.0이다.
- 점수표: 단가 A5/B3/C1, 회전율 A10/B5/C1, 리드타임 A5/B3/C1, 품질 A5/B3/C0. 종합 = 네 점수의 합.
- 회전율 = `FCST / ((기초재고 + 기말재고) / 2)`. 빈 칸(None)은 엑셀 산술처럼 0으로 본다. 분모가 0이면 회전율은 None이고 회전율 등급은 C다.
- 모집단은 구매마스터 시트의 모든 SKU 행이다. 각 백분위 배열에는 그 값이 있는 행만 넣는다.
- 구매단가가 없거나, 리드타임 등급·품질 등급이 A/B/C가 아니면 재고등급은 None이다. 메모는 `등급산출불가(사유, 사유)`이고 사유는 `구매단가없음`·`리드타임등급없음`·`품질등급없음`이다. 종합이 없는 행은 종합 배열에서 뺀다.
- 계산 등급이 실제 Z값에 쓰인다(방식 A). 엑셀 `재고등급`은 대조용으로만 쓴다.
- `data/`, `out/`은 저장소에 넣지 않는다.
- 검증 명령: `uv run pytest` 전부 통과(기존 75개 포함).

## Review Focus

1. **제목 중복:** `단가`·`회전율`·`리드타임`·`품질이슈` 제목이 두세 번 나온다. 열을 잘못 고르면 점수 열을 등급으로 읽는다. 기대 동작은 몇 번째로 나오는지로 고르는 것이다(Task 1 테스트가 실제 제목 순서로 고정).
2. **동점이 많은 값:** 종합 점수에는 동점이 많다. 백분위가 "작은 값의 개수"만 세는지 확인해야 한다(Task 2 `test_percentrank_ties`).
3. **0.26·0.75 경계:** 내림하기 전의 값이 0.2599…처럼 경계 바로 아래일 수 있다. 내림 후 비교해야 한다(Task 2 `test_percentrank_truncates`).
4. **입력이 수식인 통합문서:** 가상 보완 도구가 수식 셀(`=...`)을 값으로 착각하고 덮어쓰면 안 된다. 기대 동작은 InputError다(Task 4 `test_refuses_formula_workbook`).
5. **결과 경로가 입력과 같음:** 가상 보완 도구가 원본을 덮어쓰면 안 된다(Task 4 `test_refuses_same_path`).

def test_percentrank_ties():
    assert percentrank_inc([1, 2, 2, 3], 2) == 0.333
    assert percentrank_inc([1, 2, 2, 3], 3) == 1.0 and percentrank_inc([5], 5) == 1.0

def test_percentrank_truncates():
    vals = list(range(1, 102))            # n=101, x=27 → 26/100 = 0.26
    assert percentrank_inc(vals, 27) == 0.26 and grade_from_rank(0.26) == 'B'
    assert percentrank_inc(list(range(1, 8)), 3) == 0.333   # 2/6=0.3333… 내림
    assert grade_from_rank(0.259) == 'C' and grade_from_rank(0.75) == 'A'

def test_turnover():
    assert turnover(121, 722, 1636) == pytest.approx(121 / 1179)
    assert turnover(10, 0, 0) is None and turnover(None, 5, 5) == 0.0

def test_compute_grades_scores_and_zero_turnover():
    rows = [_row('A', price=100, b=10, e=10, f=50, lt='A', q='A'),
            _row('B', price=50, b=10, e=10, f=5, lt='B', q='C'),

**Interfaces:**
- Consumes:
  - 등급: `master_columns`(Task 1), `compute_grades`(Task 2)
  - 계산: `build_inputs(..., grades=)`(Task 3), `compute_sku`
  - 대조: `compare_with_excel`, `COMPARE_FIELDS`, `COMPARE_INPUT_FIELDS`
  - 로더: `load_*`
- Produces:
  - `summary_columns(ws) -> tuple[int, int, dict[str, int | None]]` (inventory_days/loader.py): `(제목 행, SKU 열, 표준키→열)`. `load_summary`가 이 함수를 쓰도록 바꾸고 동작은 그대로 둔다.
  - `@dataclass(frozen=True) Change`: `sheet: str, cell: str, old, new, reason: str`
  - `fill_inventory_gaps(rows: list[PurchaseMasterRow]) -> dict[str, float]`
    - 회전율 분모가 0인 SKU → 가상 기초재고(= 기말재고) 값.
    - 값 = `max(1, round(FCST / 중앙회전율 ))`. 중앙회전율은 회전율이 있는 행들의 `statistics.median`이다.
    - FCST가 없거나 0이면 1로 한다.
  - `build_virtual(src: Path, out: Path, settings: CalcSettings = CalcSettings()) -> list[Change]`
  - 명령줄: `uv run python -m safety_stock.virtual_data SRC.xlsx -o OUT.xlsx`. 끝나면 `바꾼 칸 수: N`과 결과 경로를 출력한다. InputError는 메시지를 보이고 종료 코드 2로 끝낸다.

`build_virtual` 순서(사유 문구는 그대로 쓴다):
1. `openpyxl.load_workbook(src)`(data_only 아님)로 연다. 다음 경우에는 InputError를 낸다.
   - 어느 시트에든 `=`로 시작하는 문자열 셀이 있으면: "값만 있는 통합문서가 필요합니다(수식 셀: 시트!셀)"
   - `out`이 `src`와 같은 경로면 InputError
2. 구매마스터에서 회전율 분모가 0인 행의 E·F열을 `fill_inventory_gaps` 값으로 바꾼다. 사유: `회전율 분모 0 → 가상 재고(FCST÷중앙회전율 {m:.4f})`.
3. 바뀐 통합문서로 `load_purchase_master` → `compute_grades`를 다시 돌린다. 모든 행에서 H(회전율, 소수 4자리 반올림), R, S, V~Y, Z, N 중 계산값과 다른 칸만 쓴다. 사유: `재고등급 산식 재계산`.
4. 계산(`build_inputs`, 계산 등급) → `compare_with_excel`을 돌린다.
   - 상태가 `불일치`·`엑셀값없음`이고 계산값이 있는 칸은 그 Summary 시트의 해당 칸을 계산값(반올림 없음)으로 바꾼다. 사유: `산식 결과로 교체(원래 {status})`.
   - `재고등급`·`Z값계수` 열도 계산 등급과 Z로 맞춘다.
   - 상태가 `계산값없음`이면 칸을 바꾸지 않는다. 사유 `산식으로 채울 수 없음({점검메모})`로 `Change(new=None)`만 남긴다.
5. `가상보완_내역` 시트를 새로 만든다. 제목은 `시트, 셀, 원래 값, 새 값, 사유`이고, 바꾼 칸마다 한 행이다. 그 뒤 저장한다.
