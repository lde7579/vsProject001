# 상품 적정 재고일수 자동 산출·검증 시스템 설계

- 작성일: 2026-11-19 (11/19 저녁 목적 변경 반영 개정)
- 상태: 사용자가 질문 없이 진행하기로 함 → 이 문서를 기준으로 구현 계획 작성

## 1. 배경과 목적

- 기존 MP 시스템에는 제품별 **일별 안전재고 값**(구매마스터 `안전재고 값`, 예: 기본-일자 45)이 있다. 현업이 엑셀로 입력해 왔고 정확하지 않다.
- 이 값을 산식으로 구한 **가중평균 적정 안전재고일수**(요청자 엑셀 `Summary_가중평균수요기준` S열)로 대체하는 것이 최종 목표다. 기존 값은 사용자 확인으로 리드타임 수요를 포함하지 않는 안전재고 일수다(2026-11-20 정정: 처음에는 적정 재고일수 U열로 적었으나, U는 리드타임 수요를 포함하므로 대체 대상이 아니다).
- 그 값이 얼마나 맞는지 검증하려고 **실적기준 / FCST기준 적정 재고일수**도 함께 산출해 비교한다. 더 맞는 값이 무엇인지도 찾고 싶다.
- 최종 산출물은 PPT 발표다: 왜 만들었는지, 어떤 수치끼리 비교했는지, 그래서 더 좋은 결과를 얻었는지.
- 1단계(이 문서 범위): 현재 엑셀 값(구매마스터)을 그대로 쓰는 **계산 → 엑셀 대조 → 사후 검증**을 끝까지 연결한다. 이후 단계에서 구매마스터 재고등급 자동 산출, 가중치 탐색을 붙이고, 1단계 검증으로 전후를 비교한다.

## 2. 데이터 사실 (사용자 제공 + 사진 전사로 확인)

| 데이터 | 출처 | 비고 |
|---|---|---|
| `Sales_WMS 출고` | WMS 시스템 출고실적 | 주차 WK01~ |
| `0824_02 SCM FCST`, `W35 기말재고(예상)` | MP 시뮬레이션 결과 | 주 단위 구동. 43주차 구동 결과를 44주차에 사용. 2단 헤더(1행 연도, 2행 `W35(08/24)`) |
| `0824_01 현재고` | 창고별 현재고 | SKU별 합산 |
| `W30 구매마스터` | 현업 엑셀 | 실적·FCST 가중치(엑셀 값 그대로 사용), 재고등급, 리드타임(일), 안전재고 값(=기존 시스템 일별 안전재고, 대체 대상) |
| 과소예측 보정계수 | 현업 입력 | 요청자 엑셀 Summary 시트의 `과소예측 보정계수` 열 |

요청자 엑셀(8/24 기준, 파일명 20260828) 수식과 값에서 확인한 것:
- 누적 평균은 출고 시트 전체가 아니라 **WK01~WK31**(`C:AG`)만 쓴다. 시트에는 WK34까지 있다.
- FCST 13주는 W35~W47(`H:T`).
- 표준편차는 STDEV.P.
- 실적기준·FCST기준 평균수요에는 보정계수를 곱한다. 표준편차에는 곱하지 않는다.
- 가중평균 수요는 101개 중 **81개 행만** `출고평균×실적가중치 + FCST평균×FCST가중치`와 일치한다. 나머지 20행은 다른 값이다(16행 출고평균×보정계수, 2행 FCST평균, 2행 미확인).
- 리드타임(일)은 Summary와 구매마스터 K열이 일치한다.

## 3. 목표 / 비목표 / 반목표

**목표**
- SKU별로 세 기준(가중평균·실적기준·FCST기준)의 적정 재고일수와 중간 산출값 전체를 계산한다.
- 계산값을 요청자 엑셀 Summary 값과 SKU별로 대조해 일치/불일치를 표시한다(발표 근거: "기존 엑셀은 20행이 산식과 다르다").
- 사후 검증: 8/24 시점 계산값을 그 뒤 실제 출고(W35~W43)와 비교해 어느 기준이 더 맞았는지 수치로 보인다. 기존 수기 안전재고일수도 같은 잣대로 비교한다.
- 코드를 세 영역 폴더로 나눈다(사용자 지시): ① 구매마스터 ② MP 시뮬레이션 결과(SCM FCST, 기말재고) ③ 나머지 값(WMS 출고, 현재고) + 최종값 산출·검증.
- 수식은 단위 테스트로 고정한다.

**비목표 (이번 단계 밖)**
- 재고등급 자동 산출(회전율·리드타임·품질 등급 기준 미확인) — 2단계. 폴더는 미리 둔다.
- 가중치 최적값 탐색 — 3단계.
- PPT 자체 작성, Streamlit 화면, MP 시스템 DB 연동.
- 결품확률·Dead Risk·발주우선순위.

**반목표**
- 엑셀과 다르게 계산하면서 차이를 숨기는 것. 불일치는 반드시 대조 결과에 드러난다.
- 재고등급 없는 SKU에 임의 Z값을 넣어 조용히 계산하는 것.
- 검증에 쓰는 실제 출고(W35~W43)를 계산 입력에 섞는 것(미래 정보 누수).

## 4. 접근 방식

| 안 | 내용 | 판단 |
|---|---|---|
| A. 끝까지 먼저 | 구매마스터는 엑셀 값을 그대로 읽고, 계산·대조·검증까지 연결 | **선택** — 성능을 잴 잣대가 먼저 생기고, 이후 개선(등급 산출, 가중치)을 전후 수치로 발표할 수 있음 |
| B. 구매마스터부터 | 재고등급 자동 산출을 먼저 완성 | 등급 기준 일부 미확인으로 막히고, 개선 효과를 잴 방법이 없음 |

## 5. 입력

1. **기준 통합문서**: 요청자 엑셀과 같은 구조의 xlsx(현재는 `data/재고등급_및_안전재고_수준_점검_가중평균수요_적용_20260828_사진전사.xlsx`).
   - 시트: `Sales_WMS 출고`, `0824_02 SCM FCST`, `0824_01 현재고`, `W30 구매마스터`, `Summary_가중평균수요기준`(보정계수 열과 대조용 값), `Summary_실적기준`, `Summary_FCST기준`(대조용), `W35 기말재고(예상)`(읽기만, 이번 계산엔 미사용).
   - 시트 이름은 앞부분 패턴으로 찾는다(`0824_02 SCM FCST` → "SCM FCST" 포함). 주차가 바뀌어도 쓸 수 있게.
   - 제목 행은 시트마다 다른 위치일 수 있으니(사진 속 다른 버전은 구매마스터 6행, Summary 11~12행) "SKU"/"품목 ID" 제목이 있는 행을 찾아 시작한다.
2. **사후 실적 파일**: W44 업로드 xlsx(`data/W44_가중평균수요_반영_상품_발주점검_업로드.xlsx`)의 `출고실적` 시트. 검증 구간 W35~W43만 쓴다.

## 6. 계산 (SKU별, 중간 반올림 없음)

공통 입력: 구매마스터의 `실적 가중치 wh`, `FCST 가중치 wf`, `재고등급`, `리드타임(일) LTd`, `안전재고 값(기존 일수)`, Summary의 `과소예측 보정계수 k`, 현재고 합.

| 항목 | 가중평균 기준 | 실적기준 | FCST기준 |
|---|---|---|---|
| 실적 평균 Hm | AVERAGE(출고 WK01~WK31, 빈 칸 제외) | 같음 | — |
| FCST 평균 Fm | AVERAGE(FCST 앞 13주, 빈 칸 0) | — | 같음 |
| 평균수요(주) G | Hm·wh + Fm·wf | Hm·k | Fm·k |
| 표준편차(주) σ | STDEV.P(실적)·wh + STDEV.P(FCST13)·wf | STDEV.P(실적) | STDEV.P(FCST13) |

이후 세 기준 공통:
- LTw = LTd/7, LT평균수요 K = G·LTw, LT수요편차 L = σ·√LTw
- Z = A 1.645 / B 1.282 / C 1.036
- 적정안전재고 T = L·Z, ROP = K + T
- 적정 재고일수 U = ROP / (G/7), 적정안전재고일수 S = T/(G/7), 현재고일수 E = 현재고/(G/7)
- 발주필요여부: 현재고 ≤ ROP → ORDER

실적 주차 범위(기본 WK01~WK31)와 FCST 주 수(기본 13)는 설정값으로 둔다. 기본값은 요청자 엑셀 재현용.

**예외 (점검메모 열, 여러 개면 함께)**: 등급없음(Z 관련 항목 비움), 수요없음(G=0 → 일수 비움), 실적없음/FCST없음(없는 쪽 0), 가중치합오류(wh+wf≠1, 값은 그대로 사용), 가중치없음(가중평균 비움), 리드타임없음(0 이하 포함), 보정계수없음(실적·FCST기준 비움), 보정계수이상(k=0 또는 k>3, 계산은 그대로), 구매마스터없음. 출고 시트에 행은 있으나 실적 주차가 전부 빈 칸이면 실적없음.

*(구현 중 확정: 사후 검증에서 입력 누락 기준은 채점 제외하고 사유를 남긴다. 기준 간 비교는 모든 기준을 같은 SKU로 채점하는 '공통' 범위와 품목그룹 범위로 한다. 엑셀 대조 판정은 일치/불일치/비교불가 세 가지이고 현재고도 대조한다.)*

## 7. 엑셀 대조

- 세 Summary 시트의 G, H, K, L, T, ROP, U, S를 SKU별로 계산값과 비교한다.
- 화면 표시가 반올림이므로 허용오차는 "표시 자릿수 반올림 범위"(정수 표시면 ±0.5, 유도값은 전파 허용)로 본다.
- SKU별 판정: 일치 / 불일치(어느 항목이 몇 차이인지) / 엑셀값없음.

## 8. 사후 검증 (8/24 계산 → W35~W43 실제)

비교 대상 4가지: 기존 수기(구매마스터 안전재고 값을 안전재고 일수로 봄), 가중평균, 실적기준, FCST기준.

1. **수요 예측 정확도**: 각 기준의 평균수요(주) G와 W35~W43 실제 주평균 출고 비교 → SKU별 오차, 전체 WAPE(Σ|오차|/Σ실제), 편향(Σ오차/Σ실제). 기존 수기는 수요 예측이 없으므로 제외.
2. **결품 방어율**: 리드타임이 검증 구간(9주=63일) 안에 들어오는 SKU만. 실제 LT 구간 수요(W35부터 LTd일만큼, 마지막 주는 일수 비례)를 각 기준의 목표 재고량과 비교해 "목표 재고량 ≥ 실제 LT수요"이면 방어.
   - 산식 기준의 목표 재고량 = ROP.
   - 기존 수기의 목표 재고량 = 가중평균 LT수요 + 기존 안전재고일수 × 가중평균 일평균수요. 기존 값은 사용자 확인으로 "MP UI에 사용자가 등록하는 제품별 일별 안전재고 값"이므로 리드타임 수요를 포함하지 않아 따로 더한다. 결과 시트에는 표시용 `기존수기_적정재고일수`(= 리드타임 + 기존 안전재고일수)를 함께 둔다.
   - 보정계수가 0이거나 3보다 큰 SKU(점검메모 `보정계수이상`)는 실적기준·FCST기준 채점에서 제외한다(제외사유 `보정계수이상`, 다른 제외 사유가 있으면 그것 우선). 산출결과 계산, 가중평균·기존수기 채점은 그대로이며 '공통'·품목그룹 범위에서는 자연히 빠진다.
   - 사용자 확인: FLT·ETCBID를 포함해 전 품목을 가중평균으로 계산한다.
3. **재고 부담**: 목표 재고량 / 실제 일평균 출고 = 실제 기준 재고일수. 방어율이 같다면 낮을수록 좋다.
- 요약: 기준별 대상 SKU 수, WAPE, 편향, 방어율, 재고일수 중앙값. 품목그룹별 요약도.
- 검증 대상 SKU는 두 파일에 모두 있는 SKU. 없는 SKU는 사유와 함께 목록화(SKU 코드는 `BIDSS1DR15WH`로 통일했으므로 현재 데이터에서는 BID 불일치가 없다).

## 9. 출력

- 결과 xlsx 1개(명령줄 `-o`):
  - `산출결과`: SKU별 공통 입력 + 세 기준의 중간값·적정재고일수 + 기존 일수 + 점검메모
  - `엑셀대조`: SKU별 항목 비교와 판정
  - `검증_SKU`: SKU별 실제 수요, 기준별 오차·방어 여부·실제 재고일수
  - `검증요약`: 기준별·품목그룹별 지표 (PPT 표 원천)
  - `적용기준`: 입력 파일, 실행 시각, 주차 범위, Z표, 허용오차
- 수량 정수, 일수 소수 1자리 표시(내부 값은 반올림 안 함).
- 명령줄: `python -m safety_stock 기준통합문서.xlsx --actual W44업로드.xlsx -o 결과.xlsx`

## 12. 검증 기준 (완료 조건)

1. 단위 테스트: 손계산 가능한 소형 데이터로 6장 수식 전부, STDEV.P(모표준편차), 빈 칸 처리, 예외 메모, 2단 헤더 파싱, 제목행 탐색.
2. 엑셀 재현: 전사 통합문서로 실행했을 때 `Summary_가중평균수요기준` 기준 81개 SKU가 G·H·ROP·U 일치, 나머지 20개는 불일치로 드러남. 실적기준(검산 가능한 59행)·FCST기준(42행) 평균수요 일치.
