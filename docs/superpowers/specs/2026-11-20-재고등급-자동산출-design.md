# 재고등급 자동 산출 설계 (2단계)

- 작성일: 2026-11-20
- 상태: 사용자 승인 대기
- 선행: `2026-11-19-적정재고일수-자동산출-design.md`(1단계)

## 1. 목적

현업이 엑셀에서 손으로 계산하던 `W30 구매마스터`의 **재고등급**(N열)을 프로그램 안에서 공식으로 계산한다. 원재료 값만 넣으면 매번 같은 등급이 자동으로 나와야 한다(사용자 답변 2026-11-20).

## 2. 확정한 것

- **방식 A(사용자 선택):** 계산한 등급을 안전재고 계산의 Z값에 쓴다. 엑셀 `재고등급` 열은 대조용으로만 읽는다.
- **리드타임 등급(T열)과 품질이슈 등급(U열)은 현업 입력값**으로 보고 그대로 읽는다(사용자 답변). 리드타임 일수만으로는 등급이 정해지지 않는다. 같은 FLT 그룹 14일이 A로도 C로도 나온다.
- 등급 규칙은 보완본 116행에서 거꾸로 찾았고, 116행 모두 엑셀 값과 맞는다.

## 3. 등급 규칙

모집단은 구매마스터 시트의 **모든 SKU 행**(현재 116행)이다. Summary에 있는 SKU(101개)만이 아니다.

1. **회전율** = `FCST / ((기초재고 + 기말재고) / 2)`. 분모가 0이면 값이 없다.
2. **백분위** = Excel `PERCENTRANK.INC(배열, x)`와 같게 계산한다. 값이 있는 행만 배열에 넣는다. 결과는 `x보다 작은 값의 개수 / (n−1)`이고, 소수 셋째 자리에서 **내림**한다. n = 1이면 1로 한다.
3. **단가 등급**: 구매단가의 백분위가 0.75 이상이면 A, 0.26 이상이면 B, 그 외에는 C.
4. **회전율 등급**: 같은 규칙을 적용한다. 회전율이 없으면 C다(엑셀 확인: 빈 칸 16개 모두 C).
5. **점수**: 단가 A5/B3/C1, 회전율 A10/B5/C1, 리드타임 A5/B3/C1, 품질 A5/B3/C0. **종합** = 네 점수의 합.
6. **재고등급**: 종합의 백분위에 3번과 같은 기준을 적용해 A/B/C로 정한다.

## 4. 비목표·반목표

- 비목표: 등급 기준(경계값 0.75/0.26, 점수표)을 바꿔 보는 것. 이번에는 엑셀을 그대로 옮기기만 한다.
- 반목표: 계산할 수 없는 SKU를 조용히 C로 만드는 것. 회전율 분모가 0인 경우만 엑셀 규칙대로 C로 둔다.
- 반목표: 엑셀 등급과 다를 때 차이를 숨기는 것.

## 5. 접근 방식

| 안 | 내용 | 판단 |
|---|---|---|
| A. 계산 등급 사용 + 엑셀 대조 | 계산 등급으로 Z값을 정하고, 엑셀 등급은 비교만 한다 | **선택** — 목적(수작업 제거)에 맞고, 대조로 안심도 얻는다 |
| B. 엑셀 등급 계속 사용 | 계산 등급은 보고만 한다 | 계속 수작업에 기댄다 |
| C. 명령줄 옵션으로 선택 | `--grade-source` | 지금은 두 등급이 116행 모두 같아 고를 이유가 없다 |

## 6. 만들 것

- `purchase_master/grade.py`(새 파일): 입출력 없는 순수 함수. 시트 행 목록을 받아 SKU별 결과를 돌려준다. 결과에는 회전율, 단가·회전율 백분위와 등급, 네 점수, 종합, 종합 백분위, 재고등급, 메모가 들어간다.
- `purchase_master/loader.py`: 구매단가·기초재고·기말재고·FCST, 리드타임 등급(T)·품질이슈 등급(U), 엑셀 단가 등급(R)·회전율 등급(S)·종합(Z)을 추가로 읽는다.
  - 제목 `단가`·`회전율`·`리드타임`·`품질이슈`는 등급 열(R~U)과 점수 열(V~Y)에 두 번씩 나온다. 그래서 위치를 기준으로 열을 고른다(아래 7절의 내 결정).
- `inventory_days/calc.py`: SKU 입력의 `grade`를 계산 등급으로 바꾼다. 계산 등급이 없으면 지금처럼 `등급없음`으로 처리한다.
- 결과 xlsx에 새 시트 `재고등급`을 만든다. SKU별로 입력값, 계산 중간값, 계산 등급, 엑셀 등급, 일치 여부를 적는다. 대조하는 항목은 단가 등급, 회전율 등급, 종합, 재고등급이다.
- `적용기준` 시트에 등급 규칙을 한 줄로 요약해 넣는다. 명령줄 출력에 `재고등급 엑셀 일치 SKU 수`를 추가한다.

## 7. 내 결정(검토해 주세요)

- **계산할 수 없는 경우:** 구매단가가 없거나, 리드타임·품질 등급이 비었거나 A/B/C가 아니면 재고등급을 비우고 메모 `등급산출불가(<사유>)`를 남긴다. 이런 행은 해당 백분위 배열과 종합 배열에서 뺀다.
- **회전율은 D~G열로 다시 계산한다.** H열은 대조용으로만 쓴다. 116행 일치를 확인할 때 반올림된 H열과 순위가 다르게 나오면 그 사실을 보고하고 어느 쪽을 쓸지 다시 묻는다.
- **중복 제목 처리:** 리드타임·품질 등급은 그 제목이 처음 나오는 열(T, U)이다. 엑셀 단가 등급은 처음 나오는 `단가`(R)다. `회전율`은 처음 나오는 열이 H(값)이므로, 엑셀 회전율 등급은 두 번째로 나오는 `회전율`(S)이다. 종합은 `종합`(Z)이다.

## 8. 완료 기준

- 단위 테스트: 백분위(동점, 내림, n = 1, 빈 값), 회전율 분모 0 → C, 점수표, 계산 불가 메모.
- 실데이터 테스트(보완본): 단가 등급, 회전율 등급, 종합, 재고등급이 116행 모두 엑셀과 같다.
- 1단계 검증 수치(WAPE, 결품방어율, 재고일수 중앙값)가 바뀌기 전과 같다. 등급이 모두 같으므로 같아야 한다.
- 기존 테스트 75개를 포함해 `uv run pytest`가 전부 통과한다.

## 9. 가상 보완본 (사용자 지시 2026-11-20)

사용자 지시: "산식이 맞게 가짜로 채워도 된다." 사용자는 범위를 **산식과 어긋난 칸만**으로 골랐다.

- 기존 보완본은 그대로 두고, `data/…_가상보완.xlsx`를 새로 만든다. 이 파일을 만드는 스크립트는 저장소에 넣는다. `data/`는 저장소 밖이다.
- 아래 칸만 산식 결과나 그럴듯한 가상 값으로 바꾼다. 나머지 칸은 그대로 둔다.
  - Summary 가중평균 수요 중 산식과 다른 20행
  - 회전율 분모가 0인 16행: 기초·기말재고에 가상 값을 넣고, 회전율과 각 등급을 산식대로 다시 계산한다
  - 사진에 없어 비워 둔 칸
- 바꾼 칸은 별도 시트 `가상보완_내역`에 시트, 셀, 원래 값, 새 값, 사유를 남긴다.
- 발표에는 "가상 보완 데이터 기준"이라고 표시한다. 실데이터에서 찾은 불일치(20행 등)는 발견 사항으로 따로 보여 준다.
