# 가중치 탐색 설계 (3단계)

- 작성일: 2026-11-20
- 상태: 사용자 위임으로 확정. 사용자는 "기본안대로 질문 없이 끝까지 진행하고, 판단은 직접 내린 뒤 기록"하라고 했다. 아래에서 **(내 판단)**으로 표시한 곳은 사용자가 아침에 다시 볼 대상이다.
- 선행: 1단계 설계(`2026-11-19-적정재고일수-자동산출-design.md`), 2단계 설계(`2026-11-20-재고등급-자동산출-design.md`)

## 1. 목적

가중평균 수요는 `실적평균×실적가중치 + FCST평균×FCST가중치`로 구한다. 지금 가중치는 현업이 품목그룹마다 정한 값이다.

| 그룹 | ACL | BID | FGR | FLT | MAT | SEN | WPU |
|---|---|---|---|---|---|---|---|
| 실적가중치 | 0.7 | 0.7 | 0.9 | 0.9 | 0.7 | 0.1 | 0.7 |
| SKU 수 | 1 | 1 | 2 | 70 | 31 | 4 | 7 |

이 가중치를 데이터로 다시 고르면 수요 예측이 더 맞는지 수치로 보이는 것이 목적이다. 발표의 "더 좋은 결과를 얻었나"에 답하는 근거가 된다.

## 2. 데이터 제약 (확인한 사실)

- FCST 스냅샷은 세 개뿐이다: 8/24(W35~W47), W43 파일(W43~), W44 파일(W44~).
- **WK23~WK31 시점의 FCST가 없다.** 기본안이었던 "WK01~22로 고르고 WK23~31로 검증"은 FCST 쪽 값을 만들 수 없어 쓸 수 없다.
- 실제 출고는 W44 파일에 WK43까지 있다.

## 3. 결정

- **시간 분할(내 판단):** 8/24 계산값을 그대로 두고 검증 구간을 둘로 나눈다.
  - **선택 구간 W35~W38(4주)** 실제 출고로 가중치를 고른다.
  - **검증 구간 W39~W43(5주)** 실제 출고로 지금 가중치와 새 가중치를 비교한다.
  - 가중치를 고를 때 검증 구간 데이터는 쓰지 않는다.
  - 기본안과 다른 점(과거 구간 대신 검증 구간을 앞뒤로 나눔)은 위 2절 제약 때문이다. 틀렸다면 비용은 이렇다: W38 시점에 가중치를 다시 고르는 상황을 흉내 낸 것이라, 실제 운영에서 나올 효과보다 낙관적일 수 있다.
- **후보:** 실적가중치 w ∈ {0.0, 0.1, …, 1.0}, FCST가중치 = 1 − w.
- **단위:** 품목그룹. 그룹 안의 모든 SKU에 같은 w를 쓴다. SKU별 가중치는 과적합이라 하지 않는다.
- **작은 그룹(내 판단):** 선택 구간에서 가중평균 수요오차가 있는 SKU가 **5개 미만**인 그룹은 전체 SKU를 합쳐 고른 w(공통 최적값)를 쓴다. ACL·BID·FGR·SEN이 여기에 해당할 가능성이 높다. SKU 1~4개로 고른 w는 우연에 가깝기 때문이다.
- **고르는 기준(내 판단):** 선택 구간의 가중평균 수요 **WAPE 최소**.
  - 동점이면 지금 가중치에 가까운 w를 고르고, 그래도 같으면 작은 w를 고른다.
  - 결품 방어율은 고르는 기준에 넣지 않는다. 4주 구간에서는 리드타임 28일 이하 SKU만 채점되기 때문이다. 방어율은 검증 구간과 전체 구간 결과로 보고한다.
- **비교 잣대:** 1단계의 `validate`·`summarize`를 그대로 쓴다. 지표는 WAPE, 편향, 결품방어율, 실제 기준 재고일수 중앙값이다. 기준은 가중평균과 기존수기다. 기존수기 목표도 가중평균 수요를 쓰므로 w에 따라 바뀐다.
- **기준 파일:** 명령줄로 받는다. 발표용 실행은 가상 보완본(`…_가상보완.xlsx`)으로 한다. 재고등급은 2단계 계산 등급을 쓴다.

## 4. 비목표·반목표

- 비목표: SKU별 가중치, 보정계수 k 탐색, 리드타임·Z값 탐색, 통계적 유의성 검정.
- 반목표: 검증 구간(W39~W43)을 보고 가중치를 고르는 것. 정보 누수다.
- 반목표: 선택 구간 성적만 보여 주고 개선이라고 말하는 것. 개선 주장은 검증 구간 수치로만 한다.

## 5. 만들 것

- `src/safety_stock/weight_search/`: `search.py`(순수 함수), `report.py`(xlsx 작성), `__main__.py`(명령줄)
- 명령: `uv run python -m safety_stock.weight_search BASE.xlsx --actual ACTUAL.xlsx -o out/가중치탐색.xlsx`
- 결과 시트:
  - `후보성능`: 범위(그룹 또는 전체) × w별 선택 구간 SKU 수와 WAPE
  - `선택가중치`: 그룹, SKU 수, 현재 w, 선택 w, 선택 방식(그룹최적·공통최적), 선택 구간 WAPE(현재 → 선택)
  - `검증비교`: 구간(검증 W39~43, 참고 전체 W35~43) × 범위(전체·그룹) × 가중치(현재·탐색) × 기준(가중평균·기존수기)별 지표
  - `적용기준`: 구간, 후보, 작은 그룹 규칙, 동점 규칙, 기준 파일

## 6. 완료 기준

- 단위 테스트: 후보 생성, 동점 규칙, 작은 그룹 공통 최적값, 그룹 가중치 적용, 선택 구간과 검증 구간 분리. 검증 구간 값을 바꿔도 선택 결과가 그대로인지 확인한다.
- 실데이터 실행: 결과 파일이 만들어지고, 검증 구간 가중평균 WAPE를 현재 가중치와 탐색 가중치로 나란히 보인다. 좋아지든 나빠지든 그대로 보고한다.
- `uv run pytest` 전부 통과.
